# Области эффекта на доске: план реализации

## Контекст

На доске сейчас есть только токены, фон карты и точки спауна. Заклинания и предметы Daggerheart часто создают зону, например «дым в пределах Very Close от себя», и показать её нечем. Нужна **область эффекта**: круг на доске с радиусом по дистанции SRD или в метрах. Его видят игроки, а ГМ видит, кто внутри.

Решения, принятые с пользователем:
- **Только круг.** Радиус выбирается кнопками Melee / Very Close / Close / Far или вводится в метрах.
- **Область всегда остаётся на месте.** При создании «от токена» берётся его текущая позиция. Если токен потом двигается или его удаляют, область не меняется. Двигать её можно только вручную.
- **Игроки видят области по умолчанию.** ГМ может скрыть отдельную область, например ловушку. Скрытую видит только ГМ, бледнее и с пометкой.

Первым шагом этот план сохраняется в репозиторий как `AREAS.md`, по аналогии с `PHASE1–3.md`.

## Модель данных

```js
// constants.js
makeArea(over) → { id: null, name: 'Area', x: 0, y: 0, radius: 4.5, originSize: 1,
                   color: AREA_COLORS[0], hidden: false, ...over }
// radius — метры от центра. originSize — size токена, от которого область создана (1, если от точки).
```

- Области — часть **доски**, не карты: поле state `areas: []`. Они попадают в `boardOf()` (`App.jsx:72`), поэтому undo и redo работают автоматически, и сохраняются в `localStorage` вместе с доской.
- Радиус по дистанции считается так же, как кольца (`ringRadiusM`, `constants.js`): `areaRadius(band, originSize) = DIST_METERS[band] + (originSize − 1) · 0.75`. Так область «Very Close от себя» точно совпадает с кольцом Very Close у этого токена.
- Кто внутри — `inArea(area, tok)`: `hypot ≤ area.radius + tokenRadiusM(tok) − 0.75`. Это та же логика, что у `rangeM` / `bandOf`: обычный токен внутри, если его центр не дальше радиуса, крупный считается внутри при частичном перекрытии.
- `AREA_COLORS` — 5–6 цветов: серый «дым», оранжевый «огонь», фиолетовый «магия», зелёный «яд», голубой «лёд». Цвета не должны совпадать с `DIST_COLOR`.

## Шаги

### 1. `src/constants.js`
`makeArea`, `AREA_COLORS`, `areaRadius(band, originSize)`, `inArea(area, tok)`. Рядом с `ringRadiusM` / `rangeM`.

### 2. Reducer и состояние — `src/App.jsx`
- В `initial` добавить `areas: []`. Старые сохранения получат его через слияние `{ ...fallback, ...parsed }`. В `src/storage.js` (где очищаются `tokens` при смене схемы, стр. ~42) очищать и `areas`.
- `boardOf` += `areas`.
- Действия: `ADD_AREA { area }` (id из `nextId`), `UPDATE_AREA { id, patch }`, `REMOVE_AREA { id }` входят в `BOARD_ACTIONS`. `MOVE_AREA { id, x, y }` не входит: перетаскивание делает снимок через `BOARD_SNAPSHOT` в начале, как `MOVE_TOKEN` / `MOVE_SPAWN`.
- `CLEAR` чистит и `areas`. `DEPLOY_SCENE` ставит `areas: []`, потому что сцена заменяет доску. `REMOVE_TOKEN` области не трогает.
- Новый UI-state `selectedAreaId`. Выбор области сбрасывает выбор токена, выбор токена сбрасывает выбор области. Если выбранная область исчезла (undo, удаление), выбор сбрасывается, как сейчас у `focusedId` (`App.jsx:316`).
- Клавиши (`keyRef`, `App.jsx:510`): при выбранной области Esc снимает выбор, Del удаляет область (toast с Undo), стрелки сдвигают её на 1.5 м (Shift — 0.5 м).
- Создание `handleAddArea(origin)`: центр — позиция `origin`-токена, иначе центр видимой области (`spawnCenter()`). `originSize = origin?.size ?? 1`, радиус `areaRadius('Very Close', originSize)`. Имя по умолчанию: `"<имя токена>: area"` или `"Area"`. Новая область сразу выбирается.
- Toolbar (`App.jsx:579`): кнопка **+ Area** рядом с `Spawn points`. Если выбран токен, область создаётся от него, иначе в центре экрана.

### 3. Экран игроков — `src/App.jsx`
- `STATE_UPDATE` += `areas: state.areas.filter(a => !a.hidden)`. Эффект рассылки зависит и от `state.areas`. `latestRef` тоже получает `areas`.
- Игрок: `SET_TOKENS` заменить на `SET_BOARD { tokens, areas }`. Использование только в обработчике игрока (`App.jsx:388`).

### 4. Отрисовка и жесты — `src/components/Graph.jsx`
- Новые props: `areas`, `selectedAreaId`, `onSelectArea`, `onMoveArea`. Перетаскивание использует существующий `onMoveStart`.
- Слой областей идёт после фона, сетки и точек спауна, до колец и токенов. Для каждой области:
  - `<circle>` с заливкой цветом области (`fillOpacity` ≈ 0.18, у скрытой у ГМ — 0.08) и пунктирной обводкой `vectorEffect="non-scaling-stroke"`. **Заливка не перехватывает клики** (`pointerEvents: none`), иначе большая область (Far 18 м) мешала бы панорамировать и кликать по пустому месту.
  - **Ручка у ГМ** — маркер в центре и плашка с именем и радиусом над кругом (`Smoke · 4.5 m`, у скрытой — значок 👁‍🗨/«hidden»). Только ручка интерактивна. Клик выбирает область, перетаскивание двигает её. У выбранной области обводка ярче и сплошная. У игрока ручки нет, только подпись имени.
- Жест: новый `gesture.kind: 'area'` в `beginPointer` / `onMove` / `onUp` по образцу `'spawn'` (`Graph.jsx:273`, `305–309`, `335`): движение → `onMoveArea`, тап → `onSelectArea(id)`. Тап по пустому месту в `onUp` (`Graph.jsx:340`) снимает и выбор области (`onFocusChange(null)` → App сбрасывает оба).
- `fitAll` учитывает границы областей.
- Пустое состояние доски (`Graph.jsx:365`) не показывается, если есть области.

### 5. Боковая панель — `src/components/BattleSidePanel.jsx`
- В `SelectedUnit` кнопка **Area from here** → `onAddArea(token)`.
- Новая секция `SelectedArea`, которая показывается вместо `SelectedUnit`, когда выбрана область:
  - Имя (input).
  - Радиус: chips `Melee 1.5 / VC 4.5 / Close 9 / Far 18` (через `areaRadius(band, area.originSize)`, активный chip подсвечен), плюс числовое поле в метрах (шаг 0.5).
  - Цвет: свотчи `AREA_COLORS`.
  - Чекбокс **Hidden from players**.
  - **Inside (N)**: список токенов, для которых `inArea`. Клик выбирает токен.
  - Кнопка **Remove area**.
  - Правки идут через `UPDATE_AREA`. Ввод имени и метров применяется на blur / Enter, чтобы не плодить шаги undo на каждый символ.
- Секция **Areas (N)** рядом с `OnBoard`: список областей, клик выбирает.
- Кнопка `sp-toggle` на узком экране показывает имя выбранной области, если выбрана она.

### 6. Стили — `src/App.css`
Ручка области, свотчи цветов, chips радиуса, секция областей. По образцу существующих `sp-*`, `map-notice`, `btn-on`.

## Проверка
Тестов в проекте нет: `npm run build` и ручная проверка в `npm run dev`.
- **Создание от токена:** выбрать PC → **Area from here** → круг Very Close совпадает с кольцом Very Close этого токена. Токен size 2: круг тоже совпадает с его кольцом. Сдвинуть токен — область на месте.
- **+ Area без выбора:** область появляется в центре экрана и сразу выбрана в панели.
- **Редактирование:** chips меняют радиус, поле метров принимает 6, цвет и имя меняются. Inside показывает правильные токены: на границе обычный токен считается внутри так же, как бейдж VC при выбранном токене-источнике.
- **Жесты:** перетаскивание ручки двигает область. Перетаскивание внутри большой области панорамирует доску. Клик по токену внутри области выбирает токен. Клик по пустому месту снимает выбор.
- **Undo:** создание, перемещение (один шаг на перетаскивание), смена радиуса и удаление отменяются через Ctrl+Z. Clear удаляет области и отменяется. Deploy сцены убирает области, Ctrl+Z возвращает.
- **Игроки:** `?role=player` во второй вкладке видит области без ручек. Hidden → у игрока область пропадает, у ГМ бледная с пометкой. Перезагрузка вкладки игрока → области приходят через `REQUEST_STATE`.
- **Сохранение:** перезагрузка вкладки ГМ → области на месте.
